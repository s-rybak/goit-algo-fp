# Порівняння методу Монте-Карло та аналітичних розрахунків на прикладі гральних кубиків

Алгоритм Монте-Карло для імітації підкидання двох кубиків описаний у функції `throw_two_dices`. Результати "підкидань" кубиків записувалися в словник `probabilities`, де вказана кількість випадань кожної можливої суми очок (від 2 до 12). Після отримання даних про частоту випадання кожної суми була розрахована ймовірність для кожної з них. Результати аналітичних розрахунків ймовірності випадання кожної суми були записані в словник `analytical_probabilities`.

У даному порівнянні було виконано 1 000 000 ітерацій для алгоритму Монте-Карло.

# Висновок

Як видно з результатів тесту, максимальне абсолютне відхилення ймовірностей, отриманих методом Монте-Карло, від аналітичних розрахунків становить менше 0.07 відсотка. Це можна вважати досить добрим результатом для рандомізованого алгоритму при великій кількості ітерацій. Найбільше відхилення 0.06% спостерігалося для очок 5 та 7. Найменше ненульове відхилення 0.01% спостерігалося для сум 2 та 12. Для суми 4 ймовірності, розраховані за методом Монте-Карло та аналітичним підходом, повністю збіглися і склали 8.33%.

Отже, емпірично було підтверджено, що метод Монте-Карло дає результати, близькі до аналітичних, особливо при великій кількості експериментів. Однак важливо розуміти, що цей метод є рандомізованим і не гарантує абсолютно точних результатів при будь-якій кількості експериментів. Дані, отримані за допомогою цього методу, завжди матимуть певну похибку.
